PART 1: MySQL – Database Fundamentals
==================================================

1. Data:
Data refers to raw facts or information.
It can be numbers, text, images, or any other form of information.
Example: Student name, age, marks, phone number, etc.
Data is processed to produce meaningful information.

2. Database:
A database is an organized collection of data.
It stores data in a structured way for easy access and management.
Databases help users to insert, update, delete, and retrieve data.
Example: Student database, employee database, banking database.

3. DBMS:
DBMS stands for Database Management System.
It is software used to create, manage, and control databases.
It helps users store, retrieve, update, and delete data.
Example: MySQL, Oracle, SQL Server, PostgreSQL.

4. RDBMS:
RDBMS stands for Relational Database Management System.
It stores data in tables with rows and columns.
Tables can be connected using relationships like primary key and foreign key.
Example: MySQL, Oracle, PostgreSQL.

5. Entity:
An entity is a real-world object or concept about which data is stored.
Example: Student, Employee, Actor, Product, Customer.
Each entity is represented as a table in a database.
The properties of an entity are called attributes.

6. SQL:
SQL stands for Structured Query Language.
It is used to communicate with relational databases.
SQL is used to create, insert, update, delete, and retrieve data.
Example commands: CREATE, INSERT, SELECT, UPDATE, DELETE.

7. CRUD Operations:
CRUD stands for Create, Read, Update, and Delete.
Create means inserting new data.
Read means displaying or retrieving data.
Update means modifying existing data.
Delete means removing unwanted data.

PART 3: MySQL – Queries
==================================================

-- 1. Display all records
SELECT * FROM actor_details;

-- 2. Display only actor names
SELECT name FROM actor_details;

-- 3. Display actor names and ages
SELECT name, age FROM actor_details;

-- 4. Display actors whose age is greater than 40
SELECT * FROM actor_details
WHERE age > 40;

-- 5. Display actors whose age is less than 35
SELECT * FROM actor_details
WHERE age < 35;

-- 6. Display actors whose age is equal to a specific value
SELECT * FROM actor_details
WHERE age = 41;

-- 7. Display actors whose name is a specific value
SELECT * FROM actor_details
WHERE name = 'Vijay';

-- 8. Update the age of a particular actor using WHERE clause
UPDATE actor_details
SET age = 51
WHERE name = 'Vijay';

-- 9. Delete a specific actor record using WHERE clause
DELETE FROM actor_details
WHERE name = 'Silambarasan';

-- 10. Truncate the table
TRUNCATE TABLE actor_details;

-- 11. Reinsert records after truncation
INSERT INTO actor_details (id, name, age) VALUES
(1, 'Rajinikanth', 73),
(2, 'Kamal Haasan', 69),
(3, 'Vijay', 50),
